OpenVG examples:
----------------

The examples run against the platform's own EGL/OpenVG pair when it provides
both; otherwise the build falls back to McNopper/EGL with OpenVG_Library and
executables run as built (nothing to copy).

Further information:

- README.md of this repository
- README.md of GLUS (https://github.com/McNopper/GLUS)
- README.md of OpenVG_Library (https://github.com/McNopper/OpenVG_Library)
